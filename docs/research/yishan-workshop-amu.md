## 固化为 Agent 规则

### 1. 先定义接口，再选择材料

不要先问“抽屉用木板还是亚克力”。先定义：

```text
开口净尺寸
有效抽拉行程
固定侧与运动侧
滑轨长度、侧隙和拆装方向
拉出后的重心与防倾覆
限位、把手、维修和清洁路径
目标载荷与动态系数
```

这些接口确定后，再比较成品周转箱、木盒、型材框、透明板或打印托座。标准容器能满足接口时，优先复用；只有尺寸、外观、清洁或载荷不满足时才定制。

### 2. 板厚是安装方法的输出

把“板材放进大卡槽”的需求先分成三类：

1. 槽内夹持：读取槽深、密封条和允许板厚，最后一根框边可能需要后装。
2. 平嵌支承：读取层板托或连续托条的支承标高，再反推板厚与完成面。
3. 外接固定：定义角码、支架、螺钉或嵌件，以及木材变形和工具路径。

不能从“3030”直接得出板厚。阿沐在咖啡柜回复中也是按安装方法选择层板托或支架，而不是给一个通用厚度。

### 3. 默认保留主受力构件连续性

咖啡柜案例把约 1500 mm 高立柱拆成 `815 + 505 + 200 mm`，作者说明靠墙使用时该案例够用，但也明确整根在受力上更稳。Agent 应据此生成以下检查，而不是复制“够用”：

- 分段原因是运输、加工、装配还是造型；
- 拼接节点能否传递轴力、剪力和弯矩；
- 墙体约束是否真实存在、如何连接、能否长期保留；
- 接头是否位于高弯矩区；
- 若没有必要，优先保留连续构件。

### 4. 把运动五金作为子系统

滑轨和升降机构都不是普通角码。分别维护固定件、运动件、安装基准、平行度、行程、限位、动态载荷、夹伤区、线缆弯折和维修拆卸。视频可教装配顺序，额定载荷和寿命仍查精确型号图纸。

### 5. 成本必须回到完整 BOM

“省钱”“不到 20 元”“不到 300 元”等画面文案可能只指桌面、抽屉盒、升降腿或某个零件。成本比较必须包含：

```text
型材 + 连接件 + 紧固件 + 加工 + 板材
+ 运动五金 + 电气 + 表面处理 + 运费 + 损耗 + 工具
```

缺清单时只记录“候选方案”，不记录“总价”。

### 6. 教程图纸仍需校验

板材连接篇的置顶评论指出附图中一处字段写反，作者随后确认。公开纠错提升了来源的可用性，但也说明视频附图和清单仍是待核对输入。进入 ALU 前应重新验证零件接口、数量、尺寸链和装配顺序。
