# 2026 铝型材设计知识梳理

状态：2026-08-11 完成本轮核对。范围是工业 T 槽铝型材在家具、工作台、收纳和轻型框架中的选型、连接与板材集成。

这不是采购目录或额定承载手册。厂家页面负责精确尺寸和产品能力，小红书案例只负责补充真实装配、返工与踩坑证据。

## 本轮结论

1. `2020 / 3030 / 4040` 只能用于初步检索，不能用于最终选型。外尺寸相同的型材可能属于不同槽系、使用不同紧固件，并拥有完全不同的截面惯性矩。
2. Agent 应先锁定“型材接口族”，再选连接件和板材；否则后续会出现螺母装不进、角码挡板、孔位不匹配、封闭后无法装配等问题。
3. 连接件不是装饰附件，而是包含型材、连接件、紧固件、加工、槽位占用、工具路径和装配顺序的完整节点。
4. 板材“嵌进去”至少有槽内夹持、专用压条/夹块、层板托平嵌、面装、盖板开缺口和门板轨道六类方案。不存在通用板厚或通用留缝。
5. 承重必须使用具体 SKU、真实有效跨度、边界条件、载荷分配、型材方向和厂家截面数据计算。视频中的“稳”“够用”和用途分类不能转成额定载荷。

## 证据分级

| 等级                                                         | 可用于                                                   | 不可用于                     |
| ------------------------------------------------------------ | -------------------------------------------------------- | ---------------------------- |
| 高：厂家目录、产品图纸、公开标准、可复现计算、记录完整的实测 | 精确接口、尺寸、公差、截面属性、适用范围和有边界的额定值 | 跨厂家类推                   |
| 中：多个独立实装一致、可量测但无厂家额定数据                 | 装配顺序、干涉模式、维修性、常见返工点                   | 数字承载结论                 |
| 低：单条教程、评论或营销经验                                 | 搜索关键词、候选方案、需要核对的风险                     | 额定载荷、通用尺寸、强度排序 |

任何来源一旦离开其 SKU、加载方向、安装方式或测试条件，证据等级都要下降。

## 1. 主流型材应该怎样描述

### 1.1 完整标识

一个可采购、可计算的型材定义至少需要：

```text
厂家 / 产品线 / 区域 / 目录日期
精确 SKU
模数与外尺寸
槽口宽度与槽底几何
中心孔与可加工螺纹
轻型 / 标准 / 重型 / 封闭面等截面变体
质量、Ix、Iy、Zx、Zy
安装方向
表面处理
配件兼容族
```

“欧标”和“国标”在本项目中按厂商目录分类名处理，不把名称本身当作 EN、DIN 或 GB 互换性证明。

### 1.2 2026 目录快照

[嘉立创 FA 当前型材目录](https://www.jlcfa.com/catalog/T/T01)同时列出了以下常见体系：

| 目录族        | 页面标称槽口 | 页面标称边长族                                 |
| ------------- | -----------: | ---------------------------------------------- |
| 欧标 20       |       6.2 mm | 20 / 40 / 60 / 80 mm                           |
| 欧标 30       |       8.2 mm | 30 / 45 / 50 / 60 / 90 / 120 / 150 mm          |
| 欧标 40 槽 8  |       8.2 mm | 40 / 80 / 120 / 160 mm                         |
| 欧标 40 槽 10 |      10.2 mm | 40 / 60 / 80 mm 为系列标题，具体截面继续看 SKU |
| 欧标 45       |      10.2 mm | 45 / 90 mm                                     |
| 国标 30       |       6.3 mm | 30 / 60 mm                                     |
| 国标 40       |       8.3 mm | 40 / 80 mm                                     |

这张表只用于建立候选集。同一家目录里已经存在两种欧标 40 槽系，跨厂家更不能只凭“4040”买配件。

[MISUMI 2026 年 5 月的官方指南](https://us.misumi-ec.com/blog/aluminum-extrusion-profiles-shapes-types-series-best-practices/)给出了更直观的例子：`HFS5-4040` 与 `HFS8-4040` 都是 40 × 40 mm，但模数、槽、紧固件、质量和惯性矩不同。

### 1.3 截面类别

- 方形：连接方向灵活，是框架初始候选。
- 矩形：2040、3060、4080 等适合沿一个方向提高抗弯刚度；必须把长边放在正确方向并读取对应惯性矩。
- 轻型、标准、重型：外尺寸相同但内部材料分布不同，必须视为不同 SKU。
- 封闭面、圆角、门框、拉手、线槽等专用型材：只有在外观、安全、密封、门板或布线确有要求时采用。

### 1.4 计算边界

常见理想梁筛选公式：

```text
简支梁跨中集中载荷：δ = P L³ / (48 E I)
简支梁均布载荷：    δ = 5 w L⁴ / (384 E I)
简支梁最大弯矩：    M = P L / 4 + w L² / 8
对称截面弯曲应力：  σ = M / Z
```

每个候选都要加入自身重量，并区分面板恒载、均布使用载荷、集中载荷、冲击与多个横梁的载荷分配。[MISUMI 的载荷计算资料](https://us.misumi-ec.com/pdf/fa/2010/p2431.pdf)把部分“允许载荷”定义为简支跨中载荷下挠度达到 `L/1000`；这是该资料的特定判据，不是家具行业的通用安全线。

## 2. 连接件知识地图

### 2.1 常用类别

| 类别                   | 优点                               | 主要代价                                       |
| ---------------------- | ---------------------------------- | ---------------------------------------------- |
| 外置压铸/挤压/钣金角码 | 少加工、可后装、易调、易加强       | 外露并占用外侧槽位，可能挡平嵌板、滑轨和脚轮板 |
| 外置连接板             | 同平面定位、角部或拼接补强，可后加 | 外露；未经验证不能视作刚性连续梁               |
| 内置角码/盲接件        | 外表面干净，适合门洞和面板开口     | 可能需要预装、顶丝、专用孔或额外抗侧摆方案     |
| 弹性/弹珠/简易槽内件   | 快速定位、轻载面到侧面连接         | 预紧依赖具体产品，不能默认承担框架抗侧摆       |
| 端面攻丝 + 扳手孔/沉孔 | 节点紧凑，型材端面直接贴合         | 中心孔、螺纹、孔位、螺钉和工具路径必须完全匹配 |
| 锚式连接件             | 隐藏、供应商有成套加工模板         | 横孔位置与槽口壁厚相关，不能跨系列复制         |
| 口哨/楔形连接件        | 隐藏并形成端面对接                 | 需要较大的专用盲孔和明确安装方向               |
| 二通/三维角件          | 终端多向节点紧凑                   | 常需多端攻丝，装配顺序被锁定                   |
| 一字/平行连接件        | 对齐和运输分段                     | 未经额定数据与试验，不自动承担连续梁弯矩       |
| 铰链、滑轨、活动连接件 | 门、抽屉和折叠功能                 | 需要单独处理间隙、磨损、冲击、限位和维修       |

[MISUMI 的型材页面](https://th.misumi-ec.com/en/vona2/detail/110311092599/)明确区分外置角码与需要加工的盲接；[Bosch Rexroth 目录](https://apps.boschrexroth.com/DCUS/2023/08.25.AT_Uploads/R999001283_2020-09_media-1.pdf)还说明外置连接板可以保留内侧 T 槽给面板或附件，并可在初装后补强。

### 2.2 加工不是隐含信息

[嘉立创 FA 当前工艺页](https://xc.jlcfa.com/process)分别定义端面攻丝、沉孔、扳手孔、锚式横孔、口哨盲孔和斜切。本轮已把常用系列的孔径、孔距公式、螺纹、深度和公差沉淀到 [`jlcfa-machining-2026.md`](../../skills/select-aluminum-extrusion-connections/references/jlcfa-machining-2026.md)。这些尺寸仅对嘉立创列明的系列和 SKU 有效。

节点清单至少要包含：

```text
节点 ID → 两端型材 SKU 与方向 → 连接件 SKU
→ 螺母/螺钉 → 加工面与加工码 → 占用槽位
→ 扳手方向 → 预装/后装 → 检查与复紧方式
```

## 3. 板材嵌入与固定方式

| 方法                     | 适合                     | 必查项                                           |
| ------------------------ | ------------------------ | ------------------------------------------------ |
| 槽内直接夹持 + 密封条    | 薄侧板、背板、防护板     | 实际槽深、板厚范围、热胀、装入顺序、抗振         |
| 专用压条/夹块/Multiblock | 可拆面板、较厚板、维修口 | 产品线、偏置、孔位、夹块间距、额定方向           |
| 层板托或连续托条平嵌     | 层板、桌面、台面         | 支承宽度、局部承压、板弯曲、连接件干涉、四边留缝 |
| 面装/顶装                | 厚木板、可替换台面       | 螺钉或嵌件、木材变形、外露五金、维修路径         |
| 外尺寸盖板 + 四角开缺口  | 遮住型材顶面槽口         | 模板、缺口应力、上方螺钉可达性；它不是槽内平嵌   |
| 门滑槽或铰链             | 推拉门、开门             | 轨道、导向、限位、碰撞、拆卸和动态间隙           |

几个官方产品说明了尺寸不能通用化：

- [嘉立创 `TPEV` 层板托图纸](https://static.jlcfa.com/Serial/T02/TPEV/538956682999234561.pdf)标注适用 9 mm 板材。
- [item Panel Fixing Profile 8](https://us.item24.com/index.php?eID=dumpFile&f=951&t=f&token=f4a65a632ac3967815d4ad5e93ed5cc86e0c5c8f)用于其 Line 8 槽中的 6 mm 面板。
- [item Quick Multiblock 8](https://www.item24.com/en-de/quick-multiblock-8-with-securing-pin-zn-grey-60341)针对最高 8 mm 的可拆面板，并给出该具体产品的偏置与载荷数据。
- [80/20 `12004`](https://8020.net/12004.html)作为其 20 Series 面板胶条时发布的板厚范围是 1–4 mm。

四边平嵌板的名义尺寸链可以写成：

```text
板宽 = 组框校方后的实测槽口宽 - 左缝 - 右缝
板深 = 组框校方后的实测槽口深 - 前缝 - 后缝
完成面 = 支承基准 + 板厚 + 垫片/饰面厚度
```

留缝来自型材切长公差、组框误差、板材公差、湿热变化、装入路径和期望观感，不能用一个固定经验值覆盖所有项目。

## 5. 对 Agent 的固化规则

- 先选精确接口族，再选连接件和板材方案。
- 精确 SKU 缺截面数据时只输出候选，不给“最合适”。
- 所有加工都绑定构件 ID、端面/朝向、供应商工艺和图纸版本。
- 为整个工程维护槽位占用图与装配顺序。
- 板材先定义功能与承载路径，再定义厚度和留缝。
- 小红书只进入 `constructionEvidence`，不能写入 `ratedLoad`、`allowableStress` 或通用加工尺寸。
- 厂家数值必须保存来源 URL、核对日期、适用 SKU 和条件；采购前重新核对。
