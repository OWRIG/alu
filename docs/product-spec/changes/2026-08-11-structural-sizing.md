# structural-sizing

> 状态：已完成。

## Why

当前长跨规则只在 `1500 mm` 处触发经验提醒，无法回答“在明确载荷下，哪一个具体型材最轻且满足目标挠度”。默认示例已有平嵌板做法，但没有明确载荷路径、连续主梁和节点构造，也没有把厂家截面数据转成可复算结果。

## 第一性原理

- 先定义载荷工况、有效跨度、支承模型和验收准则，再选择型材。
- 型材候选必须是具体厂家 SKU，并随工程保存质量、截面惯性矩、方向与来源。
- 构造资料只说明做法与装配，不证明数值承载；厂家截面数据只支持理想梁筛选，不证明连接、倾覆、脚轮或整机安全。
- “最合适”在本切片中指候选集里同时满足挠度准则、截面高度和接口体系，且单位质量最小的项目，不等于价格最低、全局最优或安全认证。
- 结果必须对人和 Agent 同样可读：输入、公式、分项挠度、候选比较、选择理由和未覆盖边界均可追溯。

## Delta

### ADDED `structure.beam-sizing-study`

- `.alu` 的 `extensions.structuralSizing` 保存版本化梁筛选研究：关联主梁、有效跨度参数、载荷输入、梁数与分配系数、弹性模量、挠度限值、所需接口体系、具体候选 SKU、厂家来源和构造证据。
- 默认示例使用两端简支梁的线弹性筛选，叠加台面质量、均布使用载荷、最不利单梁跨中集中载荷与候选型材自重。
- 计算均布与集中载荷挠度、最大弯矩、弹性弯曲应力、限值利用率和给定基础均布载荷下的跨中质量上限。
- 候选必须同时通过挠度、截面高度和接口体系过滤，再按单位质量最小选择；若均不通过则不输出推荐。

### ADDED `editor.sizing-panel`

- 右侧新增 `Sizing / 选型` 页，允许编辑台面质量、均布使用载荷与集中载荷。
- 页面显示有效跨度、载荷分配、公式、候选 SKU、截面惯性矩、双梁质量、接口体系、计算挠度、约束状态和最小质量推荐。
- 页面同时显示厂家计算依据、构造资料和未覆盖的连接、侧摆、倾覆、脚轮与实物验证边界。

### CHANGED `structure.long-span-review`

- 被有效研究覆盖的主梁不再只显示通用长跨提醒；检查页改为显示带数值的挠度筛选结果或“无候选通过”。
- 结果明确限定为理想梁挠度筛选，不输出额定承载或结构安全结论。

### CHANGED `example.clearance-frame-construction`

- 平嵌板由四边内托结构承托，并保留组框后实测要求。
- 两根纵向主梁保持连续，避免未验证拼接进入主要弯曲路径。
- 主节点预留补强空间；连接件、加工和紧固件仍作为未决项。
- 组合连接件、侧横杆和层板托进入装配顺序，避免框架封闭后失去安装路径。
- 这些构造要求只进入拓扑与装配说明，不进入数值承载公式。

## Not in this change

- 不做有限元、连接刚度、局部屈曲、疲劳、冲击、倾覆、脚轮额定值或法规认证。
- 不把台面视为与铝型材共同受力的组合梁。
- 不把定性构造描述转换成额定载荷。
- 不新增 headless 写入 API、完整采购 BOM 或自动下单。

## Cases

- `C-structural-study-portable` 研究输入、候选快照与证据随 `.alu` 保存重开，结果可确定性重算。
- `C-beam-superposition` 均布、跨中集中载荷与型材自重按公开公式叠加，黄金数值在误差范围内稳定。
- `C-minimum-mass-passing-profile` 默认工况中 3030/4040 挠度不通过，欧标 LCF 候选接口不兼容，`NFSL8-4080` 通过并以最低质量入选，标准 `NEFS8-4080` 也通过但更重。
- `C-sizing-load-edit` 修改任一 kg 输入只产生一步历史，候选结果、检查 finding 与保存内容同步更新。
- `C-sizing-no-fake-rating` 界面、规则、文档和 Skill 均把结果限定为理想梁挠度筛选，不声称整机安全或认证承载。
- `C-construction-evidence-separation` 构造资料仅支持拓扑与装配决策，数值计算只引用厂家截面数据与公式。
