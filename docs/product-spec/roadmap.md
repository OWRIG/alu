## 范围

### 做

- 工业铝型材骨架、连接节点、加工和配套零件建模
- 面板、脚轮等与型材结构直接相关的附件
- 可复核 BOM、切割表、加工表和装配提示
- 自定义零件目录与工程包流通
- 英文优先、完整简中入口、离线优先、Agent 友好的桌面编辑器

### 不做

- 通用实体 CAD、自由曲面、机械装配全功能或 FEA
- 自动声称结构安全、额定承载或厂家可加工
- 第一阶段的云协作、账号、商城、下单和支付
- 允许工程文件执行 JavaScript 的插件系统

## 阶段

1. **P0 工程基线**：Electron 安全边界、目录、Zod schema、质量门禁。
2. **P1 纵向切片**：参数尺寸链、型材建模（属性编辑）、只读 3D 投影、`.alu` 保存重开、型材切割 BOM。
3. **P2 节点与完整 BOM**：拖拽与吸附交互、连接件、紧固件、加工、板材、脚轮、装配顺序。
4. **P3 自定义目录与流通**：自定义零件、工程内嵌目录、导入冲突处理、CSV/JSON 导出。
5. **P4 Agent 接口与效率工具**：headless CLI 与配套 skill、命令预览、批量生成、规则解释、模板和参数化家具向导。
6. **P5 分发**：先交付 macOS arm64 安装包与内容回归，再补公证自动化、Windows、其他架构与升级。

## 开放问题

1. 第一批正式型材与连接件数据来自通用目录还是嘉立创目录快照。
2. P2 是否继续使用简化矩形包络，还是为已验证 definition 引入真实 T 槽轮廓。
3. 首个 BOM 交换格式除 CSV/JSON 外，是否立即支持 XLSX。
4. Windows、macOS x64/universal 的优先级，以及 Apple 公证凭据如何进入 CI。
5. 哪些结构规则能获得厂家公开数据支持，哪些只能保留为经验警告。
6. 线性组合公式何时不够用（min/max、数量 × 间距），版本化公式 AST 的扩展触发条件。
7. live attach（连接运行中应用、实时观看 agent 建模）的触发场景与机制。
