# 编辑器与尺寸链

## 当前行为

应用启动后载入参数化跨障碍框架示例。左侧先显示关键结果，再把输入按“空间边界 / 框架包络 / 嵌板装配”分组；完整派生尺寸默认折叠。用户修改输入值后，线性尺寸链按拓扑顺序求值，所有仍同步的字段绑定在同一条领域命令中更新。

首次启动默认使用简体中文，可通过顶部工具栏的地球图标完整切换为英文。语言选择保存到本机并在重载后恢复，同时同步到 Main 的原生打开、保存和未保存关闭弹窗；已有设置不会因默认值变化而被覆盖。固定界面文案、内置样例名、内置参数名、默认构件用途、概念型材名、通知、错误和规则解释一起切换；文件名、稳定 ID、坐标轴、单位和用户自己输入的内容保持原样。语言选择器是唯一有意同时展示“English / 简体中文”的位置。

左侧参数面板既能修改输入值，也能新建、编辑和删除输入参数与线性派生参数。派生公式由“参数 + 系数 + 常数项”显式组成，不执行公式字符串；仍被公式、构件绑定或选型研究引用的参数不会被隐式级联删除。空白工程因此可以从实测输入开始建立自己的尺寸链。

默认跨障碍框架采用四边围框平嵌板：顶框外轮廓 `2230 × 500 mm`，40 mm 围框形成 `2150 × 420 mm` 槽内净空，18 mm 板按单边 2 mm 安装缝取 `2146 × 416 mm`，板面与顶框上沿齐平。两根纵向长梁初始使用 4080 概念包络；顶框侧梁、立柱和底梁使用 4040 概念包络。`casterInstalledHeight` 初值为 `0 / 待确认`；填写真实安装总高后，底框与立柱起点等量抬高、立柱切长等量缩短，顶面高度保持不变。内侧托条目前只是 3D 概念参照，不进入型材 BOM。

右侧“选型”页读取工程内的结构化梁研究。用户可编辑台面质量、均布使用载荷和跨中集中载荷；每次提交只产生一步历史，并立即重算有效跨度、分项挠度、候选自重、弹性应力、截面高度与可选接口体系约束、候选状态和最小质量结果。截面高度上限与实际截面尺寸使用不同参数。用户显式点击“应用到模型与下料”后，关联梁才替换为带厂家、SKU、截面和来源的精确 definition snapshot；载荷变化不会静默替换已应用型材。

右侧构件页支持新增、选择和删除矩形型材，并通过属性编辑起点、X/Y/Z 主轴、切长、用途与 0°/90°/180°/270° 截面朝向。3D 画布是工程实体的只读投影；相机操作不会改变工程。

被参数绑定的切长允许手工覆盖，但会显示失同步。用户可以重同步或解除绑定，系统不会在后续参数修改时静默覆盖失同步值。

所有工程修改进入 100 步历史。撤销后提交新命令会清空旧的重做分支。

## 限制

- 没有拖拽、吸附或 transform gizmo；P1 通过数值属性移动构件。
- 只有矩形截面包络，没有真实 T 槽网格。
- 选型页不验证具体连接件 SKU、材料许用应力、侧摆、倾覆或脚轮额定值与接口。
