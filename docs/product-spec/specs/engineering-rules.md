# 工程检查

## 当前行为

检查面板从当前工程生成可解释 finding。每项包含稳定 rule ID、严重度、涉及实体、原因、证据类型与置信度、建议动作和阻断目标。

P1 硬错误在 schema、参数求值或领域命令边界阻止不合法工程落地。经验规则只给 warning，不输出确定承载值、“安全”或“合格”结论。

当前已启用：

- 长主跨挠度复核与截面朝向提醒。
- 移动结构缺少横撑/斜撑的侧摆提醒。
- 木地板优先软质轮面。
- 移动电器结构的线缆路径提醒。
- 人身承载或儿童攀爬时要求专业结构复核。
- 参数字段失同步提醒。

## Cases

| Case                      | 已验证结果                                                   |
| ------------------------- | ------------------------------------------------------------ |
| `C-rule-hard-error`       | 参数成环、非法长度、缺失 definition 等错误阻止提交或文件解析 |
| `C-rule-advisory-warning` | 黄金样例稳定触发长跨、移动侧摆、木地板轮面和线缆四类 warning |
| `C-rule-no-fake-rating`   | 无厂家数据或计算时，输出中不出现数值额定承载或结构安全结论   |

## 证据边界

内置 2020/3030/4040/4080 definition 是矩形包络，证据置信度为 low。经验阈值用于提示复核，不代表厂家能力、法规认证或结构计算。
