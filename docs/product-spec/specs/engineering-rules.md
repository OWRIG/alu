# 工程检查

## 当前行为

检查面板从当前工程生成可解释 finding。每项包含稳定 rule ID、严重度、涉及实体、原因、证据类型与置信度、建议动作和阻断目标。

P1 硬错误在 schema、参数求值或领域命令边界阻止不合法工程落地。经验规则只给 warning，不输出确定承载值、“安全”或“合格”结论。

当前已启用：

- 有结构化研究时，按公开简支梁公式叠加载荷与自重，并按挠度、截面高度、接口体系和单位质量筛选具体厂家 SKU。
- 没有有效研究覆盖时，保留长主跨经验复核与截面朝向提醒。
- 移动结构缺少横撑/斜撑的侧摆提醒。
- 木地板优先软质轮面。
- 移动电器结构的线缆路径提醒。
- 人身承载或儿童攀爬时要求专业结构复核。
- 参数字段失同步提醒。

## Cases

| Case                             | 已验证结果                                                                       |
| -------------------------------- | -------------------------------------------------------------------------------- |
| `C-rule-hard-error`              | 参数成环、非法长度、缺失 definition 等错误阻止提交或文件解析                     |
| `C-rule-advisory-warning`        | 黄金样例用计算型 info 取代通用长跨 warning，并保留侧摆、木地板轮面和线缆 warning |
| `C-rule-no-fake-rating`          | 无厂家数据或计算时，输出中不出现数值额定承载或结构安全结论                       |
| `C-beam-superposition`           | 台面、均布载荷、候选自重和跨中集中载荷按公开公式分项叠加                         |
| `C-minimum-mass-passing-profile` | 只在同时满足挠度、高度和接口体系的候选中选择单位质量最小项                       |
| `C-sizing-no-fake-rating`        | 反算质量上限和弹性应力均不被表述为额定承载或材料强度通过                         |

## 证据边界

内置 2020/3030/4040/4080 definition 是矩形包络，证据置信度为 low。结构研究另存具体 SKU 的厂家质量、强轴惯性矩、接口体系与来源；其结果仍只覆盖理想梁挠度筛选，不验证具体连接件、整机稳定、法规认证或结构安全。
