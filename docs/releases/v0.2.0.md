# ALU 0.2.0 alpha

ALU 0.2.0 makes aluminum-extrusion selection inspectable by a person and an Agent. It replaces the bundled example's “long span, probably 4080” heuristic with a versioned load case, exact vendor section data, explicit constraints, reproducible beam equations, and candidate-by-candidate rejection reasons.

![Exact-SKU comparison and component derivation](https://raw.githubusercontent.com/OWRIG/alu/v0.2.0/docs/images/example-sizing-comparison-en.png)

## What changed

- A new Sizing tab edits panel mass, distributed payload, and worst-beam midspan point load, then recalculates all candidates immediately.
- `.alu` projects can carry a validated `structuralSizing` v1 study: beam IDs, effective span, load shares, deflection criterion, section-height limit, required interface family, exact candidate snapshots, calculation sources, and construction evidence.
- The pure domain evaluator superposes simply supported uniform-load, profile-self-weight, and center-point deflection. It also reports elastic bending stress and the point mass implied by the deflection limit without calling either a rated load.
- Seven exact MISUMI SKUs are compared by strong-axis inertia and mass. Eligibility requires deflection, section height, and interface-family compatibility; the remaining set is ordered by mass per meter.
- The bundled frame now reserves 4080 only for the two long beams and uses a lighter 4040 concept envelope for the end rails, uprights, and base rails.
- The bundled frame now records explicit construction decisions: a flush panel inside a four-sided pocket, continuous primary members, reinforced load joints, preloaded connectors, side rails, and shelf supports. Construction notes remain separate from numeric capacity evidence.
- English remains the first-launch default, with a complete Simplified Chinese entry. All new sizing content, results, checks, and evidence labels are localized.
- The `design-with-alu` Skill now requires exact loads, effective span, SKU, inertia, orientation, geometry constraints, interface family, source URLs, rejection reasons, and unresolved physical checks.

## Default study result

At the bundled default's `2190 mm` effective span, ALU evaluates a `12 kg` panel, `30 kg` distributed payload, `15 kg` worst-beam midspan payload, candidate self-weight, `E = 69,972 N/mm²`, and the MISUMI `L/1000` criterion.

`NFSL8-4080` is selected at `1.80 mm ≤ 2.19 mm`, with a two-beam cut mass of `9.46 kg`. `LCF8-3090` is lighter and calculates to `1.55 mm`, but it exceeds the `80 mm` envelope and belongs to the incompatible Euro accessory system. Standard `NEFS8-4080` also passes but is heavier.

The formulas and criterion come from MISUMI's [simply supported beam calculation](https://cn.c.misumi.com.cn/book/sh2_2018_msm_fa_01/pdf/2147.pdf) and [allowable-load workflow](https://cn.c.misumi.com.cn/book/sh2_2018_msm_fa_01/pdf/2146.pdf). Exact profile values are linked in the [structural-sizing documentation](../engineering/structural-sizing.md).

## Boundary

This is an ideal-beam deflection screen, not a frame load rating or safety approval. It does not validate exact connector SKUs, joint flexibility, local slot failure, allowable material stress, panel composite action, sway, tipping, casters, impact, fatigue, or proof testing. The profile-only cut list still excludes connectors, machining, fasteners, casters, panels, and accessories.

## Install

Download `ALU-0.2.0-arm64.dmg`, open it, and drag ALU into Applications. The ZIP contains the same Apple Silicon application. `design-with-alu-0.2.0.zip` installs the standalone Agent Skill.

The app is Developer ID signed and uses hardened runtime, ASAR, restrictive production loading, and Electron fuses. It is **not Apple-notarized**; macOS may report `Unnotarized Developer ID` on first launch. Verify the checksums and source before proceeding.
