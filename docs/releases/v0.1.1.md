# ALU 0.1.1 alpha

ALU is now positioned around its actual product primitive: agent-readable industrial aluminum-extrusion design, not one furniture example.

## What changed

- English is the first-launch default; Simplified Chinese remains a complete, persistent interface entry, including native file dialogs.
- The bundled project is now presented as a `Parametric Clearance Frame` with generic obstacle IDs in newly created `.alu` files.
- Existing 0.1.0 projects with overbed-table names and legacy bed/mattress IDs remain compatible.
- The default GitHub README is English and leads with the verifiable Agent contract: strict project data, explicit dimensions, deterministic projections, explainable findings, and a versioned Skill.
- New English and Simplified Chinese illustrated examples document the generic constraint-to-handoff workflow.
- `design-with-alu` now triggers for general aluminum-extrusion frame work and produces a structured handoff without claiming unsupported headless writes.

Geometry, profile cut-list aggregation, and engineering-rule algorithms are unchanged from 0.1.0.

## Current Agent boundary

`.alu` v1 is inspectable, validated JSON, but 0.1.1 does not expose a supported headless mutation API. Apply writes through the desktop editor so schema validation, revision checks, parameter bindings, and derived projections remain intact.

## Install

Download `ALU-0.1.1-arm64.dmg`, open it, and drag ALU into Applications. The ZIP contains the same Apple Silicon application. `design-with-alu-0.1.1.zip` installs the standalone Agent Skill.

The app is Developer ID signed and uses hardened runtime, ASAR, restrictive production loading, and Electron fuses. It is **not Apple-notarized**; macOS may report `Unnotarized Developer ID` on first launch. Verify the checksums and source before using the documented open procedure.
