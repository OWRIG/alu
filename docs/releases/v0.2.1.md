# ALU 0.2.1 alpha

ALU 现在以简体中文作为新用户的首次启动语言，完整英文界面继续保留。已有用户保存过的语言选择不会被覆盖。

[English documentation](https://github.com/OWRIG/alu/blob/v0.2.1/README.en.md)

![界面语言菜单](https://raw.githubusercontent.com/OWRIG/alu/main/docs/images/language-menu-zh.png)

## 变化

- Renderer 与 Main 共用一个 `zh-CN` 默认语言常量，界面和原生文件弹窗不会出现默认值漂移。
- 语言菜单先列简体中文，再列 English；点击顶部工具栏的地球图标即可切换。
- 语言选择保存在本机，重载和重启后继续生效。
- GitHub 根 README 改为简体中文，顶部保留完整英文文档入口。
- 英文 README 和英文图文示例明确说明语言切换路径、持久化范围与不翻译的数据边界。
- 新增中英文语言菜单截图。结构选型算法、`.alu` 文件格式与工程数据没有变化。

## 安装

下载 `ALU-0.2.1-arm64.dmg`，打开后把 ALU 拖入 Applications。ZIP 包含同一份 Apple Silicon 应用；`design-with-alu-0.2.1.zip` 是可独立安装的 Agent Skill。

应用已做 Developer ID 签名并启用 hardened runtime，但尚未 Apple 公证；macOS 首次打开时可能显示 `Unnotarized Developer ID`。

## 验证

- `pnpm ready`：83 条产品规格 case、16 个测试文件、50 项测试、类型、lint、格式、边界和生产构建通过。
- `pnpm test:e2e`：真实 Electron 覆盖简中首启、中文保存与重载、英文切换与持久化、选型、参数、BOM、保存和重开。
- `pnpm docs:screenshots`：中英文编辑器、语言菜单、下料、选型与检查截图已重新生成并人工复核。
- `pnpm package:verify`：arm64 应用、7.1 MiB ASAR、Electron fuses 和 `en` / `zh_CN` locale 边界通过。
- `pnpm test:package`：签名后的应用通过简中首启、英文切换、参数、BOM、保存和重开 smoke。
- `design-with-alu` 通过官方 Skill validator。
- `codesign --verify --deep --strict` 与 `hdiutil verify` 通过。
- `spctl --assess` 按当前 prerelease 边界返回 `source=Unnotarized Developer ID`。
