# ALU 0.1.0 alpha

首个可运行的 macOS Apple Silicon alpha。

## 包含

- 移动跨床桌参数尺寸链与平嵌桌板概念装配。
- 型材构件编辑、只读 3D、确定性型材切料清单和可解释检查。
- `.alu` v1 打开、原子保存、最近工程和重开校验。
- 完整简体中文 / 英文界面与原生文件弹窗。
- `design-with-alu` Agent Skill、图文示例和可复现的 DMG / ZIP 构建流程。
- Electron sandbox、context isolation、受限 preload、IPC 来源校验与发布 fuses。

## 安装

下载 `ALU-0.1.0-arm64.dmg`，打开后把 ALU 拖入 Applications。

Agent Skill 可单独下载 `design-with-alu-0.1.0.zip`，解压后把 `design-with-alu` 目录放进 `~/.codex/skills/`。

### macOS 信任状态

- 已使用 `Developer ID Application: Rig Xu (77C27K6Z5A)` 签名，hardened runtime 与 sealed resources 校验通过。
- 当前未做 Apple 公证；Gatekeeper 会显示 `Unnotarized Developer ID`。这是 prerelease，不应对外宣称为无提示安装包。
- 审阅源码和下方 checksum 后，如 macOS 阻止首次打开，可在 Finder 中按住 Control 点按 ALU 后选择“打开”，或到“系统设置 → 隐私与安全性”确认。

## 重要边界

这是概念设计 alpha。输出不包含完整连接件、加工、紧固件、脚轮、板材或附件 BOM，也不构成结构计算、额定载荷、制作图或安全认证。采购和制作前必须核对厂家目录、现场尺寸、挠度、抗侧摆与装配细节。
